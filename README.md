## 📖 About

Sruput Jamu adalah website landing page untuk brand minuman
jamu modern yang menggabungkan cita rasa tradisional dengan
konsep minuman yang lebih modern dan refreshing.

Website ini dirancang dengan visual yang playful dan modern
untuk memperkenalkan produk, varian rasa, keunggulan, serta
mengarahkan pengunjung menuju pembelian.
